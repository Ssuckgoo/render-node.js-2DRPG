# 던전 파티

1~4인 협동 던전 탐험 액션 RPG. 마우스로 이동/공격, 키보드로 스킬. 맵 위에서 실시간으로 싸운다.
FastAPI + WebSocket, 그래픽은 브라우저 캔버스로 직접 그린다(이미지 파일 없음).

## 로컬 실행

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

http://localhost:8000 접속 → 방 만들기 → 초대 링크 공유.

## Render 배포

1. 이 폴더를 GitHub 저장소로 push
2. Render 대시보드 → New → Blueprint → 저장소 선택 (`render.yaml` 자동 인식)
   - 수동으로 만들 경우: Web Service / Python / Free
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. 헬스체크/깨우기용 엔드포인트: `/healthz`

> 방 정보는 메모리에만 있으므로 서버가 재시작되면(재배포, 슬립) 진행 중인 방은 사라진다.

## 게임 규칙

- 층마다 64x48 던전이 랜덤 생성. 계단을 찾아 파티 전원이 계단 주변에 모이면 다음 층
- 3층마다 보스(고블린 왕 → 리치 → 드래곤, 이후 강해지며 반복). 체력 50% 이하에서 광폭화 + 새 패턴
- 보스를 잡으면 마을로: 상인(장비/물약 구매, 판매), 대장장이(강화 +10까지), 포탈로 다음 층
- 몬스터 특수 능력: 분열(슬라임), 재조립(해골), 자폭(임프), 돌진(오크), 원거리(궁수/광신도), 소환(강령술사/뱀파이어)
- 바닥의 빨간 원/선은 공격 예고 — 피하면 안 맞는다
- 쓰러지면 15초 후 동료 옆에서 부활 (사제는 즉시 부활). 전원 쓰러지면 게임 오버
- 스킬 트리: 레벨업마다 포인트 1. 직업별 액티브 4개(Q W E R, R은 Lv.6 궁극기) + 패시브 3개
- 장비 8부위(무기/투구/갑옷/장갑/신발/목걸이/반지x2). 무기는 직업 전용
- 등급: 일반 · 희귀 · 영웅 · 전설(고유 효과) · 세트(2/4세트 효과)

## 조작

- 마우스 누르고 있기: 커서 쪽으로 이동 / 몬스터 클릭: 다가가서 자동 공격 / 상인 클릭: 대화
- Q W E R (또는 1~4): 스킬 — 마우스 커서 위치를 겨냥. F: 물약
- I: 가방 (끌어서 장착, 우클릭 장착/해제, 상점에선 우클릭 판매) / K: 스킬 트리
- Enter: 채팅, Esc: 위장 화면(회의록)

## 구조

| 파일 | 역할 |
|---|---|
| `game/data.py` | 직업·스킬 트리·몬스터 능력·장비·세트·고유 효과 수치 (밸런스 조정은 여기) |
| `game/items.py` | 장비 생성, 강화, 가격 |
| `game/dungeon.py` | 던전/마을 맵, 길찾기, 벽 충돌 |
| `game/engine.py` | 게임 규칙 (0.1초 틱: 이동, 몬스터 AI/보스 패턴, 전투, 스킬, 마을) |
| `main.py` | 방 관리, WebSocket, 틱 루프 |
| `static/sprites.js` | 16x16 도트 스프라이트 정의 |
| `static/app.js` | 렌더링/이펙트, 시야, 미니맵, HUD, 가방·스킬·상점 창, 입력 |
